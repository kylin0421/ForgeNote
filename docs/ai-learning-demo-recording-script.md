# ForgeNote「ai学习」录屏展示稿

## 1. 视频定位

- 建议时长：约 4 分钟（正常语速约 220～250 字/分钟）。
- 建议标题：**ForgeNote：从理解学生到持续进化的 AI 学习工作台**
- 核心叙事：**理解学生 → 深度检索 → 多 Agent 协作 → 多模态生成 → 练习评估 → 画像回写**
- 演示主题：用 Transformer 的 Q、K、V 展示一次完整的个性化学习闭环。
- 操作方式：打开 `ai学习` 后，每按一次空格推进一个预置步骤，共 14 步。除首次打开 Notebook 外，录制中不需要输入文字或等待在线模型。

> 录屏中不要称它为“预置演示 Notebook”或“特殊演示入口”。把它当作一个普通学习 Notebook，自然讲解产品能力即可。

## 2. 录制前准备

1. 确认前端、API、数据库和任务 Worker 均已启动。
2. 使用 Chrome 打开 `http://127.0.0.1:3000/notebooks`。
3. 建议使用 1920×1080、浏览器缩放 90%～100%，隐藏书签栏和无关扩展图标。
4. 使用深色主题或当前产品默认主题；整段录制不要切换主题。
5. 关闭系统通知、聊天弹窗和密码管理器提示。
6. 将鼠标停在画面空白处。按空格前确认输入框没有焦点，避免空格被输入框接收。
7. 每次按下空格后停顿约 1 秒，等转场与动画稳定后再开始下一句旁白。
8. 正式录制前完整试走一次，确认以下链路均能出现：
   - Notebook 学生画像和个性化对话
   - DeepSearch 检索计划、并行搜索和证据结果
   - Multi-Agent 工作流监督台
   - Studio 多模态资产：指南、导图、辅助图片、讲解视频、播客和 Quiz
   - Quiz 作答、讲解和画像回写

### 重置方法

如果误按空格、旁白说错或需要重录：

1. 返回学习记录列表；
2. 重新点击 `ai学习`；
3. 页面会从一个全新的 Notebook 状态重新开始，进度恢复为 `0 / 14`。

## 4. 录制节奏提示

- 每次转场后先让观众看清画面，再说功能名称。
- 旁白优先解释“为什么有价值”，不要逐字朗读界面。
- DeepSearch 段落重点展示“检索计划、来源类型、证据综合”，不要只停留在搜索动画。
- 监督台段落至少停留 40 秒，这是 ForgeNote 区别于普通 AI 学习产品的关键镜头。
- 多模态段落应让辅助图片、视频播放器、思维导图、指南和音频播放控件都在画面中出现；如空间有限，可从图片与视频缓慢滚动到播客，避免快速来回移动。
- 最后务必停在“画像更新 + 下一步路径”画面，让观众记住这是一个会持续学习学生的闭环系统。
